# Ghi công

Keyboard Builder Simulator dùng các model và texture bên thứ ba dưới đây. Văn bản giấy phép đầy đủ nằm
trong thư mục [`licenses/`](licenses/). Danh sách này cũng hiện trong game ở **Cài đặt → Ghi công**
(nguồn dữ liệu: `src/data/credits.ts`).

## Desolder suction effect

- Suction layer: Joseph SARDIN, “Suction cup on plastic”, CC0, https://bigsoundbank.com/suction-cup-on-plastic-s1261.html. Trimmed first pop; layered with synthesized spring click.
- Desolder pump and spool holder: user-provided CAD files, converted using scripts/convert-desolder-pump.mjs and scripts/convert-spool-holder.mjs.
