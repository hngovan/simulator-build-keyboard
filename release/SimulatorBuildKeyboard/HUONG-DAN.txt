SIMULATOR BUILD KEYBOARD — bản test

WINDOWS
  1. Giải nén toàn bộ file zip ra 1 thư mục.
  2. Bấm đúp "Choi-game.bat". Trình duyệt tự mở game ở http://localhost:8080
     (cổng bận thì tự dùng 8081, 8082...).
  3. Giữ cửa sổ đen mở khi chơi; đóng nó là tắt game.
  Nếu Windows hỏi "Windows protected your PC": bấm "More info" → "Run anyway".

MAC / LINUX (cần Python 3, máy Mac có sẵn)
  Mở Terminal trong thư mục "game" rồi chạy:   python3 -m http.server 8080
  Sau đó mở trình duyệt: http://localhost:8080

LƯU Ý
  - Dùng Chrome / Edge / Firefox bản mới, máy có card đồ hoạ cho mượt.
  - Không mở trực tiếp index.html bằng cách bấm đúp: trình duyệt sẽ chặn tải model 3D.
  - Tiến độ lưu trong trình duyệt của máy đang chơi.
  - Bản test, chỉ dùng nội bộ: một số model 3D chưa rõ giấy phép, không đăng lại / chia sẻ công khai.
