# Mechanical Keyboard Switch Lube Station

- Source: https://www.printables.com/model/55397-mechanical-keyboard-switch-lube-station
- Author: Fonz
- Files downloaded: switch module, stems module, left/right accents, connector.
- The station module holds 35 Cherry MX style switches; the stems module holds up to 85 stems.
- Runtime assets are generated into `public/models/lube/` by `bun run convert:lube-station`.
